# Edge AI Journey

一个面向 **边缘 AI 工程与研究** 的学习型仓库，目标是：

- 建立体系化知识（硬件架构 + 编译部署 + 模型优化）
- 持续动手实验（可复现、可量化、可比较）
- 形成行业判断（技术趋势 + 产品落地 + 投资逻辑）

## 仓库结构

```text
.
├── README.md

├── 00-roadmap.md
```

## 学习原则

1. **先整体再细节**：先掌握端到端链路，再深入某一模块。
2. **先可跑再优化**：先得到可运行结果，再做性能与精度优化。
3. **每周复盘**：将本周输入、输出、问题、下一步记录到 `CHANGELOG.md`。

## 快速开始

- 阅读总路线图：[`00-roadmap.md`](./00-roadmap.md)
- 从基础笔记开始：[`notes/01-fundamentals`](./notes/01-fundamentals)
- 选择一个实验动手：[`experiments`](./experiments)
